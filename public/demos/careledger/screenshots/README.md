# CareLedger 포트폴리오 핵심 기능

Playwright가 실제 공개 데모 흐름을 조작해 캡처한 화면입니다. 합성 이미지가 아닙니다.

1. **Excel·CSV 불러오기 및 자동분류**
   - 거래내역을 불러와 표준화하고, 분류 근거가 충분한 거래는 자동분류합니다.
   - 애매한 거래만 담당자 검토 대상으로 남깁니다.
   - 화면: `01-excel-auto-classification.png`

2. **담당자 검토·보정 및 전송 승인**
   - 검토 대상의 계정과목을 사람이 확정하고, 전송 전 점검 후 승인합니다.
   - 승인 시점의 전송 내용을 유지해 승인 후 임의 변경을 막습니다.
   - 화면: `02-review-approval-ready.png`

3. **부분 실패 처리 및 실패 건만 재전송**
   - 일부 거래가 실패해도 성공 건을 다시 보내지 않고 실패 건만 재전송합니다.
   - 동일 요청을 유지해 중복 실행 위험을 줄입니다.
   - 화면: `03-partial-failure-retry.png`

4. **전송 이력 및 원장·전송 결과 대사**
   - 최초 전송, 실패 건 재전송, 최종 결과 확인을 실행 이력으로 남깁니다.
   - 재처리 후 원장 금액과 전송 결과의 차이가 0원인지 확인합니다.
   - 화면: `04-transfer-history-reconciliation.png`

> 실제 희망이음 운영 시스템이 아닌 독립 테스트 연동 환경의 포트폴리오 시연입니다.
