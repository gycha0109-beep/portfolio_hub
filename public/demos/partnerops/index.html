거래처 접수·정산 현황 조회 시스템

문의 없이 직접 확인하고,
관리자는 한 곳에서 운영합니다.

Google Drive·Excel로 관리하던 접수·정산 업무를 웹으로 옮기는 상황을 가정했습니다. 관리자가 거래처·접수·정산 정보를 등록하면 각 거래처는 로그인 후 자사 데이터만 조회하는 구조입니다.

관리자 화면 확인거래처 화면 확인
요구사항 대응

공고에서 필요한 핵심 흐름을 그대로 재현했습니다.

화면뿐 아니라 서버 구현·자동 검증까지 별도로 구성했습니다.

거래처별 조회
자사 데이터만

각 거래처 계정은 자기 접수·정산 내역만 조회하도록 설계했습니다.

관리자 운영
한 곳에서 관리

거래처·계정 발급, 접수 등록·상태 변경, 정산 관리를 한 화면 흐름으로 구성했습니다.

기존 데이터 이관
Excel → DB

기존 Excel을 바로 저장하지 않고 검증·오류 확인 후 이관하는 흐름을 구현했습니다.

운영 안정성
자동 검증

관리자→거래처 전체 업무 흐름과 거래처 간 데이터 분리를 자동 테스트합니다.

화면 확인

관리자와 거래처 화면을 바로 비교할 수 있습니다.

정적 데모에서는 로그인 대신 역할을 직접 선택합니다.

ADMIN

관리자 백오피스

거래처 등록·계정 발급, 접수·정산 등록과 상태 변경, Excel 이관 Preview를 확인할 수 있습니다.

 PARTNER A

알파네트웍스

알파네트웍스에 속한 접수·정산 데이터만 조회하는 거래처 화면입니다.

 PARTNER B

브릿지렌탈

브릿지렌탈 데이터만 별도로 표시되어 거래처 간 정보 분리를 비교할 수 있습니다.
검증 근거

화면 시안에 그치지 않도록 실제 구현도 검증했습니다.

관리자 업무 흐름
PASS

거래처 생성 → 계정 발급 → 접수/정산 등록 → 거래처 조회까지 브라우저에서 검증했습니다.

기존 Excel 이관
검증 후 반영

잘못된 행을 먼저 표시하고 검증을 통과한 데이터만 DB에 반영하도록 구성했습니다.

데이터 저장 구조
PostgreSQL

거래처·사용자·접수·정산·이관 이력·감사 로그를 분리 관리합니다.

공개 데모 안내: 공개 데모에서는 화면과 업무 흐름을 빠르게 확인할 수 있도록 합성 데이터 기반 정적 화면을 제공합니다. 실제 로그인, 서버 세션, 관리자 데이터 변경, PostgreSQL 거래처별 접근 제한, Excel DB 반영 로직은 비공개 서버 구현과 자동 테스트에서 검증했습니다.
